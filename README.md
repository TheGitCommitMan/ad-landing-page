## 📋 Features
- **Smart Link Frame:** Responsive `iframe` rendering configured target links.
- **Stacked Ad Grid:** Integrated multi-container ad script placements.
- **Referrer Control:** `<meta name="referrer" content="no-referrer-when-downgrade" />` header configuration.
- **Responsive Styling:** Flexible dark layout built using pure CSS.
